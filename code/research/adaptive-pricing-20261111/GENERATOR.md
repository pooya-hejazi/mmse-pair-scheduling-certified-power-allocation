# Native CDL holdout for adaptive pricing

Freeze this specification and `generate.py` before drawing one 128-bit root entropy value. The input generator receives no schedules, objectives or method outputs. Use all twenty blocks, three independently drawn CDL-A/B/C populations in each block, and the three paired SNR values 0, 10 and 20 dB. There is no new pilot. Development uses previously registered populations.

Use the November 11 priced-assignment seed hierarchy and unchanged native link generator. Spawn main and bootstrap namespaces, then block, profile and purpose within main. Each profile has sixteen channel seeds, sixteen large-scale-offset seeds, one initialization seed and one stochastic-search seed. Reuse this profile's channels, offsets and solver seeds across its three SNRs. Reserve the common bootstrap stream. Persist the entropy, spawn keys and all 2,041 effective uint32 identifiers. Reconstruct the preceding study's exclusion set including both November 10 registries and their actual draft pilot channel and offset identifiers. Take its union with all 2,041 November 11 priced-assignment purpose identifiers. Reject an effective-seed collision before generating any input. These checks concern identifier reuse. They do not establish disjoint pseudorandom trajectories.

Each user is static and has one vertically polarized omnidirectional antenna. The common receiver has two vertically polarized omnidirectional elements spaced half a wavelength apart. Use Sionna 2.2.0, specification version 19.2, CPU float64/complex128, uplink direction, a 3.5 GHz carrier, and a 100 ns delay spread. Fix BS and UT orientations at (0, 0, 0) and (π, 0, 0). Retain the raw, unnormalized responses on tone indices (−14, −10, −6, −2, 2, 6, 10, 14) at 50 MHz/32 spacing. Draw an independent frequency-flat offset uniformly on [−6, 6] dB for every user. Multiply the native tones by `sqrt(10**((snr_db + offset_db)/10)/0.1)`. Use 0.001–0.2 W per user and a 2.08 W total budget. The three SNRs within a block and profile are paired observations from the same channels.

From the repository root, run the following commands with the original generation environment (Python 3.12.10, NumPy 2.5.4, CPU Torch 2.15.0, Sionna 2.2.0). The two generation commands are for a fresh output directory or an interrupted generation. `prepare` writes the seed manifest once. A distributed checkout already contains the frozen outputs.

```sh
python -B code/research/adaptive-pricing-20261111/generate.py prepare
python -B code/research/adaptive-pricing-20261111/generate.py generate
python -B code/research/adaptive-pricing-20261111/generate.py verify --regenerate-links
```

Each `inputs/native-bXX-P.npz` retains the native CIR, delays, eight-tone responses, array geometry, offsets and input identifiers. `inputs/catalog.json.gz` retains the original per-case header and metadata, including the binary64 scale factors. The public native path in the case metadata refers to its new `inputs/` location. The archived scientific converter reconstructs the exact gains and pair correlations from the scaled binary64 components. `generate.load_case(name)` returns the complete JSON-compatible dictionary. `generate.case_bytes(case)` emits its original field order as UTF-8 JSON with two-space indentation, LF line endings and no trailing newline. `input_check.json` lists a SHA-256 for each of the 180 case encodings, for each of the 60 native files, for the catalog and for the seed manifest. Published data omit the redundant expanded rational strings.

The generator checks that restored cases reproduce the digests taken from the direct Sionna generator's dictionaries after the path relocation. It separately reconstructs every pair coefficient by Gaussian-integer arithmetic, checks native channels by direct Fourier summation and retrieves all 960 CIRs, delays and frequency responses a second time from their registered Sionna seeds. Ordinary stored-input verification uses Python and NumPy only. Run `python -B code/research/adaptive-pricing-20261111/generate.py verify` from the repository root. The `--regenerate-links` option also checks the pinned Sionna PHY source files, runtime versions, and byte-level native reconstruction.
