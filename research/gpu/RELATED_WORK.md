## GPU capability versus exactness

[NVIDIA cuOpt introduction](https://docs.nvidia.com/cuopt/user-guide/latest/introduction.html) describes GPU LP/QP and a beta MIP solver combining GPU primal work with CPU branch-and-bound. That does not establish a polynomial exact solver for general ILP. The [system requirements](https://docs.nvidia.com/cuopt/user-guide/latest/system-requirements.html) specify Linux or Windows via WSL2, compatible CUDA and Python; the existing native Windows CuPy environment is not an installed cuOpt environment. The local pilot therefore uses CuPy for coefficient construction and an explicitly experimental LP method, with CPU HiGHS reference. No cuOpt benchmark or GPU-MILP speedup is claimed.

Any runtime comparison must match formulation, variable family, objective, feasibility tolerance, optimality gap, hardware, threads, warmup, transfer/setup, and stopping budget. Reporting fewer iterations or a fractional/infeasible vector as a faster ILP solution is invalid.
