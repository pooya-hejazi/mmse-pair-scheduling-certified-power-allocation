# Preliminary comparator eligibility

31 October 2026. No new baseline runs or formal 30-paper review. Suitability depends on the eventual accepted model; publication recency alone is insufficient.

| Method/source | Useful capability | Scope difference and fair use |
|---|---|---|
| [Jiang–Schotten 2025](https://arxiv.org/abs/2508.20708) | Centralized/distributed uplink combining, max–min power control, fairness/capacity/fronthaul comparisons. | Max–min objective and different combining structures. Use as architecture evidence or adapt with explicit disclosure; not an unchanged sum-rate pair-scheduling baseline. Audit rank assumptions before implementing displayed ZF inverse: the listed local dimensions can make the Gram matrix singular. This is an implementation-eligibility concern, not a finding that all paper results are invalid. |
| [Liesegang et al. 2026](https://arxiv.org/abs/2605.27930) | Imperfect-CSI heterogeneous services, energy efficiency under QoS, analytical fractional programming and attention GNN. | Statistical/finite-blocklength service model differs from instantaneous pair MMSE sum rate. Their objective, constraints, training and inference costs must be accounted for before quantitative comparison. Source code linked by paper: https://github.com/Nokia-Bell-Labs/gnn-power-control-heterogeneous-cfmmimo ; not executed here. |
| [ProxySelect 2025](https://arxiv.org/abs/2510.15452) | Group selection using rate proxies and an integer optimization model. | Downlink ZF; a proxy-exactness result is not an integrality theorem. Reimplementation would be an adaptation, with shared candidate family and coefficient cost. |
| Adapted I-WMMSE/SLSQP already in this repository | Continuous local power refinement on a shared fixed schedule. | Retain existing negative improvements. These are feasible local solutions, not global optima or complete scheduling algorithms; match initialization, starts and wall time. |
| Grid ILP/LP plus the present rounding allowance | Discrete optimum / upper bound with an explicit power-discretization allowance. | LP bound needs validated dual feasibility; restricted candidate columns need missing-column control. Current coarse-grid allowance near 9% cannot establish a 1% continuous certificate. |
| Generic global spatial branch-and-bound / standard perspective relaxation | Reference tools for nonconvex continuous power / concave activated blocks. | Must include setup, coefficient generation, feasible recovery, dual/pricing error, timeout and memory. No new measured result here. |

Prospective metrics: net throughput with bandwidth and overhead; total/user radiated power; energy efficiency with declared circuit/fronthaul denominator; fifth-percentile rate and QoS violation; primal/upper bound gap; end-to-end wall time, memory and timeouts. Compare identical channel realizations, CSI access, resource budget, eligible schedules and power domains. A global guarantee for a discrete power grid is not a guarantee for the continuous problem.
